### Laboratorium

Warunkiem zaliczenia jest **zaliczenie kolokwium oraz projektu**.

**Kolokwium** sprawdza wiedzę i umiejętności objęte zajęciami laboratoryjnymi.

**Projekt** jest rozwijany etapami. Każda osoba musi zaimplementować
**co najmniej dwie różne mikrousługi** oraz pozostałe wymagane komponenty
systemu.

Ocena projektu obejmuje:

- **jakość i kompletność kodu — 60%,**
- **jakość dokumentacji — 40%.**

Dokumentację należy rozwijać wraz z projektem.
